# TCK 店頭在庫モニター

Googleスプレッドシートの在庫を、店内の横長モニターへ大きく表示するGitHub Pages用サイトです。

## 表示条件

| 列 | 内容 | サイトでの扱い |
|---|---|---|
| A | カード名 | 商品名として表示 |
| B | 無視 | 使用しない |
| C | 画像リンク | カード画像として表示 |
| D | 無視 | 使用しない |
| E | 販売価格 | 通常価格として表示 |
| F | 在庫数 | 1以上なら通常価格を表示 |
| G | 状態特価 | 状態特価として表示 |
| H | 特価在庫数 | 1以上なら状態特価を表示 |
| I以降 | 無視 | 使用しない |

F列またはH列のどちらかが1以上の商品だけを表示します。両方が1以上なら、通常価格と状態特価を同じ商品内へ並べます。行の順番はスプレッドシートの順番をそのまま使用します。

## 1. Apps Scriptを設定する

1. 対象スプレッドシートを開きます。
2. `拡張機能` → `Apps Script` を開きます。
3. エディタ内の既存コードを削除し、このフォルダの `Code.gs` を全文貼り付けます。
4. データが先頭のシートにない場合だけ、冒頭の設定を変更します。

```javascript
const MONITOR_SETTINGS = {
  sheetName: "販売在庫",
  headerRow: 1,
  cacheSeconds: 20
};
```

5. `testMonitorData` を選択して一度実行し、権限を許可します。
6. 実行ログに `"ok": true` と商品データが出ることを確認します。
7. 右上の `デプロイ` → `新しいデプロイ` を押します。
8. 種類は `ウェブアプリ`、実行ユーザーは `自分`、アクセスできるユーザーは `全員` を選びます。
9. デプロイし、`/exec` で終わるウェブアプリURLをコピーします。

スプレッドシート自体を一般公開する必要はありません。ただし、ウェブアプリURLが返すカード名・画像・価格・在庫数は、URLを知っている人から閲覧できます。読み取り専用で、サイトからシートを編集する機能はありません。

## 2. GitHub Pagesを公開する

1. GitHubで新しい公開リポジトリを作成します。
2. `index.html` をリポジトリ直下へ追加します。
3. `Settings` → `Pages` を開きます。
4. `Build and deployment` で `Deploy from a branch` を選びます。
5. Branchを `main`、フォルダを `/(root)` にして保存します。
6. 数分後に表示されるGitHub PagesのURLを開きます。

## 3. モニターへ接続する

初回表示時に設定画面が開きます。

1. Apps Scriptの `/exec` URLを貼り付けます。
2. 画面タイトル、商品名の表示／非表示、1画面の商品数（最大20商品）、切替時間、在庫更新間隔を選びます。
3. `保存して接続` を押します。
4. 右下の全画面ボタンを押します。

設定はそのモニターのブラウザへ保存されます。別の端末では、最初に同じURLをもう一度設定してください。

## モニター操作

| 操作 | 内容 |
|---|---|
| `←` / `→` | 前後のページへ移動 |
| `Space` または `P` | 自動ページ切替の停止・再開 |
| `R` | 在庫を即時更新 |
| `F` | 全画面表示・解除 |
| `S` | 設定画面を開く |

マウスを動かすと右下に操作ボタンが表示され、しばらく操作しないと自動で隠れます。

## 動作確認用デモ

GitHub PagesのURL末尾へ `?demo=1` を付けると、Apps Scriptを設定する前でもサンプル商品で表示を確認できます。

```text
https://ユーザー名.github.io/リポジトリ名/?demo=1
```

## 画像が表示されない場合

- C列は `https://` から始まる画像URLを使用してください。
- Google Drive画像の場合は、画像ファイルを閲覧できる共有設定が必要です。
- 通常のDrive共有URLと `=IMAGE("URL")` のどちらにも対応しています。
- 外部サイト側が画像の直接表示を禁止している場合、そのURLは利用できません。

## Apps Scriptを変更した場合

コードを変更しただけでは、公開済みウェブアプリへ反映されない場合があります。`デプロイ` → `デプロイを管理` → 編集から、新しいバージョンとして再デプロイしてください。ウェブアプリURLは通常そのまま利用できます。
